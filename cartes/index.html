Le Joker Parle
Main posée sur le cœur pendant 3 secondes.
Donne droit à une seule phrase orale de 10 mots maximum.
Le Carnet de Poche
Autorisé pour les pensées plus complexes.
Règle stricte : 3 mots maximum par note.
Le Code Tactile
1 pression sur le poignet = « Je suis là ».
2 pressions = « Regarde-moi ».
